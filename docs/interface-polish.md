# Interface polish

All five tabs retain their mounted state after the first visit: selections, filters, comparisons, unfinished research slips, expanded sections, and independent search/scroll positions survive navigation. Unvisited tabs are lazy code chunks and do not fetch data. Hidden tabs are removed from the accessibility tree; dashboard polling, ticker motion, the playbook, and market timers pause while inactive. Scroll positions last for the current browser session in memory, not across a hard reload.

Public JSON uses a bounded in-memory cache (24 URLs), concurrent-request deduplication, 15-second request timeout, and per-consumer cancellation. Prices/props/status cache for at most one minute; other exports cache for five minutes. Revisiting the main research tabs revalidates expired snapshots without clearing controls or blanking existing data. Failed/non-JSON responses are not cached. No sportsbook API requests are introduced. Market quote/kickoff eligibility is still recalculated from the actual clock; selecting an offer still uses its saved evidence. Existing slip legs retain their original evidence when source data revalidates.

Pages and first-load data have static placeholders. Controls share restrained press/hover/focus feedback, 180ms page and modal transitions, and 220ms probability/bar updates. Probability wheel nodes keep their identity and no longer bounce/replay from zero on every selection. Reduced motion disables transitions, animations, and smooth scrolling. Dialogs lock scrolling, make background controls inert, retain focus trapping, and restore focus on close.

Markets uses a compact game selector, a separate Cross-game ideas workspace, a horizontal market selector, and collapsed probability/model options. Source evidence is available through each offer's disclosure. Stake/combined-price/target validation explains errors inline without saving invalid values or substituting odds. The supplied DraftKings PNG is resized to an appropriate transparent PNG rather than re-illustrated.

Checklist priorities implemented: load-speed/code splitting, image compression, mobile target sizes and full-width search, keyboard focus/skip link, improved muted text contrast, default description/social metadata, native-brand social preview, and a branded static 404. Decorative images intentionally use empty alt text when adjacent labels supply the same meaning. There are no frontend API-key environment variables; credentials remain in server-side GitHub workflow secrets. The existing Pages hosting configuration is unchanged. Privacy/terms content, tracking analytics, cookie consent, and spam protection were not added: this pass adds no collection or submission endpoints and does not invent policy commitments.

Performance figures are controlled local-preview measurements, not production/mobile-network guarantees. CI saves loading/interaction/accessibility and network measurements with screenshots; the production build reports route chunk sizes. Hash routes share a single HTML document and its social metadata; they are not separate indexable pages. A sitemap would not make the hash tabs separately indexable.
