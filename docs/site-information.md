# Footer and site information

The shared footer retains the Intercepted brand and adds a tagline, creator credit, exploration links, model/source information, an existing-data-status shortcut, public GitHub issue feedback, copyright with a dynamic year, Privacy, and Terms. The third-party ownership and independence statements do not claim rights over provider content.

The `#methodology`, `#privacy`, and `#terms` routes use the existing hash router and retained page shell. Direct links, reloads, back/forward navigation, document titles, keyboard focus, and main-tab state preservation remain available. Information content is lazy loaded. There are no placeholder legal links or new forms, accounts, trackers, storage keys, or requests. The data-status button opens and focuses the existing refresh disclosure without changing the page hash.

Privacy describes the inspected implementation: browser-local research slips/paper records; temporary in-memory controls and public-data cache; no app-set cookies, advertising pixels, audience analytics, accounts, or payments; GitHub Pages hosting; direct ESPN score and NFL headshot requests; local exports; and public GitHub issue reports. It distinguishes local-data retention and deletion from provider-held logs. No private contact address, retention promise, jurisdiction, compliance certification, or sale-of-data assertion is invented.

Terms covers research-only output, availability, paper simulations, quote verification, original versus third-party rights, respectful use, and applicable non-excludable rights. Methodology explains model families, uncertainty, conditional player appearances, TD event distinctions, QB tracking gaps, verified versus retrospective evaluation, model health, source credits, and refresh/market limitations.
